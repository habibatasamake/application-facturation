📚 Partie 1 : Les Fondamentaux de l'Orchestration IA

1.1 Pourquoi orchestrer l'Intelligence Artificielle ?

Jusqu'à présent, l'utilisation de l'IA reposait sur un échange unitaire : un humain pose une question, le modèle répond. Cependant, dans un contexte d'entreprise moderne, 95% des données à valeur ajoutée proviennent d'événements automatisés : la réception d'une facture, l'arrivée d'un nouveau prospect dans un CRM, un avis négatif publié en ligne, ou une actualité stratégique.

Un orchestrateur d'automatisation (comme Make ou n8n) fait le pont entre le monde réel et le cerveau de l'IA. Il écoute en continu les événements, extrait les informations pertinentes, consulte le modèle linguistique approprié, puis applique des règles d'action concrètes.

1.2 Les 4 piliers d'un workflow intelligent

1. Le Déclencheur (Trigger)
Le point de départ du flux. Soit par Polling (interrogation régulière toutes les X minutes), soit par Webhook (signal instantané envoyé par une application tierce).
2. Le Conteneur de Données (JSON)
La structure clé/valeur universelle comprise par toutes les API modernes, permettant de nommer chaque information reçue.
3. Le Connecteur LLM (Module IA)
L'appel API vers OpenAI (GPT-4o), Google (Gemini) ou Anthropic (Claude). On lui injecte un Prompt Système strict et des variables dynamiques.
4. Le Routage Conditionnel (Filters)
L'aiguillage du flux selon l'analyse de l'IA (ex: si note d'urgence > 8 → envoi de SMS ; sinon archivage discret dans une base).

TP 1 Make en Pratique : L'Assistant Automatique de Veille & Qualification (40 min)

Scénario professionnel : Votre organisation reçoit en continu des flux d'actualités technologiques. Vous allez concevoir un scénario Make qui lit chaque nouvel élément, charge un modèle de langage (OpenAI ou Gemini) de rédiger une synthèse et d'évaluer la criticité (score de 1 à 10), puis envoie une alerte prioritaire uniquement si le score est supérieur ou égal à 7.

[Flux RSS / Webhook] ──▶ [OpenAI / Gemini LLM] ──▶ [Module JSON Parse] ──▶ [Router] ├── (Score >= 7) ──▶ [Email / Slack / Discord] └── (Score < 7) ──▶ [Google Sheets / Archivage]
1
Initialisation du scénario et Déclencheur RSS

Connectez-vous sur make.com, créez un nouveau scénario et ajoutez le module RSS > Watch RSS feed items.

Entrez l'URL d'un flux d'actualités tech : https://techcrunch.com/feed/ et fixez la limite à 1 article. Faites un clic droit sur le module > "Run this module only" pour charger les premières variables dans Make.

2
Connexion et Configuration du Module IA (OpenAI / Gemini)

Ajoutez le module OpenAI > Create a Chat Completion (ou module Gemini). Sélectionnez le modèle gpt-4o-mini ou gemini-1.5-flash.

Prompt Système (à coller dans System Role) : Tu es un analyste de veille stratégique. Pour chaque article soumis, analyse le contenu et renvoie UNIQUEMENT un objet JSON strictement valide au format suivant, sans texte introductif : { "titre_court": "Titre percutant en 5 mots", "resume_executif": "Synthèse claire en 2 phrases", "score_pertinence": (Entier entre 1 et 10), "thematique": "IA, Sécurité ou Business", "action_recommandee": "Action concrète à entreprendre" } Prompt Utilisateur (User Message) : Titre : {{1.title}} Contenu : {{1.description}}
3
Conversion de la réponse avec le module "Parse JSON"

L'IA renvoie du texte brut. Pour transformer ce texte en véritables variables cliquables, ajoutez le module JSON > Parse JSON.

Dans le champ JSON String, glissez la variable de réponse de l'IA : {{2.choices[].message.content}}.

4
Routage Conditionnel & Filtrage Intelligent

Ajoutez un Router. Créez deux chemins distincts :

  • Branche 1 (Alerte Immédiate) : Module Email, Slack ou Discord. Cliquez sur la clé à molette entre le Router et ce module pour poser le filtre : {{3.score_pertinence}} >= 7.
  • Branche 2 (Archivage Passif) : Module Google Sheets ou Tools pour enregistrer les articles moins prioritaires ({{3.score_pertinence}} < 7).
💡 Astuce pédagogique : Faites exécuter le bouton "Run once" aux étudiants. Demandez-leur d'ouvrir la bulle d'inspection du module JSON pour vérifier comment Make a décomposé le score et le résumé en variables manipulables.

TP 2 n8n en Pratique : L'Agent IA Autonome avec Outils & Mémoire (40 min)

Changement de paradigme : Contrairement à Make où nous avons fixé manuellement chaque embranchement (If/Else), dans n8n nous allons créer un Agent IA doté d'outils. L'agent va décider lui-même s'il doit utiliser un outil externe ou s'il sait répondre seul, tout en conservant la mémoire de la conversation !

[Chat Trigger Node] (Interface Web de test) │ ▼ ┌────────────────────────────────────────────────────────┐ │ AI AGENT NODE │ │ (Agent autonome basé sur l'architecture LangChain) │ └───────┬──────────────────────┬──────────────────┬──────┘ │ │ │ [Model Node] [Memory Node] [Tool Node] (OpenAI / Gemini) (Window Buffer) (Calculator)
1
Créer le Déclencheur "When chat message received"

Dans un nouveau workflow n8n, ajoutez le déclencheur When chat message received (Chat Trigger). Ce nœud fournit directement une fenêtre de messagerie pour tester l'agent.

2
Ajouter le Nœud "AI Agent" (Tools Agent)

À la sortie du Chat Trigger, insérez le nœud AI Agent et choisissez le type Tools Agent. Remarquez les trois connecteurs inférieurs :

  • Model : Fournit la capacité de réflexion.
  • Memory : Fournit la continuité conversationnelle.
  • Tools : Fournit les capacités d'action dans le monde réel.
3
Connecter le Modèle et la Mémoire Buffer
  • Sous le port Model : Branchez un nœud OpenAI Chat Model (ou Google Gemini Chat Model).
  • Sous le port Memory : Branchez un nœud Window Buffer Memory (configurez la taille de l'historique à 5 messages).
4
Connecter l'Outil "Calculator" et Rédiger la Consigne Système

Sous le port Tool, connectez le nœud d'outil Calculator. Ouvrez ensuite le nœud AI Agent et définissez le System Message :

Tu es l'assistant commercial d'une société informatique. Tu réponds toujours avec courtoisie en français. RÈGLE CRITIQUE : Pour tout calcul numérique, pourcentage, remise commerciale ou taxe, tu as l'interdiction de deviner le résultat. Tu dois OBLIGATOIREMENT invoquer ton outil "Calculator" pour obtenir un résultat exact au centime près.
5
Test en direct dans l'interface de Chat & Observation des Traces

Ouvrez l'onglet de chat de n8n et faites exécuter successivement ces 3 tests aux étudiants :

  • Test 1 (Dialogue normal) : "Bonjour, que vends-tu comme services ?" → L'agent répond sans utiliser l'outil.
  • Test 2 (Raisonnement avec outil) : "Un client achète 15 serveurs à 1 240 € HT. On applique 8% de remise puis 20% de TVA. Quel est le montant TTC final ?" → Observez la séquence Thought → Action: Calculator → Observation → Final Answer !
  • Test 3 (Persistance mémoire) : "Quel était le prix unitaire du serveur mentionné juste avant ?" → L'agent retrouve la valeur grâce à son nœud mémoire.

🛡️ Règles d'Or de Production & Sécurité (15 min)

1. Jamais de clés d'API en dur

Toujours déclarer les clés dans les gestionnaires sécurisés d'identifiants (Credentials n8n ou Connections Make).

2. Le danger des boucles infinies

Si un flux répond automatiquement à un email, il risque de boucler avec les répondeurs automatiques. Ajoutez toujours un filtre anti-boucle.

3. Optimisation des Tokens

Ne pas transmettre un email complet avec signatures et mentions légales au LLM. Prétraitez le texte pour ne garder que le message utile.

4. Human-in-the-Loop

Pour les actions sensibles (paiement, envoi client officiel), l'IA prépare le brouillon et un humain valide via un bouton d'approbation.

🧠 Quiz d'Évaluation Rapide (5 Questions)

1. Dans une automatisation, quelle est la spécificité d'un Webhook par rapport au Polling ?
a) Le webhook coûte plus cher en calcul serveur.
b) Le webhook transmet la donnée instantanément dès que l'événement a lieu (temps réel). ✔
c) Le webhook ne sait pas transporter de JSON.
2. Pourquoi utilise-t-on le module "Parse JSON" dans Make après l'appel à l'IA ?
a) Pour traduire le résultat en français.
b) Pour transformer le bloc de texte brut du LLM en variables structurées utilisables dans les filtres. ✔
c) Pour crypter la réponse de l'IA.
3. Qu'est-ce qui distingue le nœud "AI Agent" de n8n d'un module d'IA classique ?
a) Il est gratuit et ne nécessite aucune clé d'API.
b) Il utilise un raisonnement autonome pour décider s'il doit invoquer un outil connecté ou répondre directement. ✔
c) Il ne fonctionne qu'avec des fichiers PDF.
4. Pourquoi confier le calcul mathématique à l'outil "Calculator" plutôt qu'au LLM seul ?
a) Les LLMs ont tendance à faire des erreurs sur les calculs précis et les arrondis financiers. ✔
b) L'outil Calculator utilise moins de mémoire RAM.
c) Le LLM refuse systématiquement de manipuler des chiffres.
5. Si une banque exige que ses données sensibles ne sortent jamais de son réseau local, quelle solution adopter ?
a) Make.com avec un abonnement Pro.
b) n8n auto-hébergé sur ses propres serveurs (On-premise / Docker) avec un modèle local (Ollama). ✔
c) Zapier en mode Cloud.
