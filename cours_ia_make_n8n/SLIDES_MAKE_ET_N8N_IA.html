Concept Fondamental
Du Chatbot Ponctuel au Système Autonome
❌ Le Goulot d'Étranglement Humain
• Un lead arrive sur le site → L'employé ouvre ChatGPT → Il copie le message → Il demande une qualification → Il colle la réponse dans le CRM → Il envoie un email manuel.

Conséquences : Perte de temps colossale, indisponibilité la nuit et le week-end, risque d'erreurs de saisie.
✅ Le Flux d'Orchestration d'API
• Le formulaire envoie un Webhook instantané à l'orchestrateur.
• L'orchestrateur transmet le texte à l'IA avec une grille d'évaluation stricte.
• L'IA renvoie un score et un résumé en 1,2 seconde.
• Le flux met à jour le CRM et alerte l'équipe commerciale sur Slack 24/7.
Événement Réel (Formulaire / Email) ──▶ [Orchestrateur] ──▶ [Modèle IA] │ │ (Analyse & Note) ▼ ▼ [CRM / Notion] ◀── [Alerte Slack / SMS]

⚡️
1. Trigger
L'étincelle initiale.
• Polling : Vérifie toutes les 15 min.
• Webhook : Poussé en direct (temps réel).

La langue universelle des API. Paire clé / valeur pour transmettre l'info sans ambiguïté.
🧠

Le cerveau analytique. Reçoit le Prompt Système + variables dynamiques et renvoie une décision.
🔀
4. Routeur & Filtre
L'aiguillage conditionnel. Exécuter l'action A (Urgent) ou l'action B (Archivage).

Matrice Décisionnelle
Make vs n8n : Quel Outil Choisir et Quand ?
Critère Make n8n
Cible & Prise en main 100% No-code visuel, parfait pour équipes marketing, RH, ventes Fair-code, hybride No-code / JS / Python pour profils tech
Hébergement & RGPD 100% Cloud SaaS propriétaire (données transitent chez Make) Cloud OU Auto-hébergé sur serveur privé (souveraineté totale)
Intégration de l'IA Appels séquentiels classiques (OpenAI, Gemini) Nœud "AI Agent" natif (LangChain, Outils autonomes, Mémoire)
Tarification Facturé au nombre d'opérations (chaque bulle = 1 op) Facturé au flux (Cloud) ou 100% gratuit illimité (Docker self-host)
💡
La règle empirique : Si vous devez connecter Google Sheets à Notion rapidement avec une équipe non-technique, utilisez Make. Si vous concevez un agent IA doté d'outils ou nécessitant une stricte confidentialité des données, utilisez n8n.
TP 1 • 40 min
Make : Veille & Synthèse Stratégique Automatisée

Mission de l'atelier : Créer un scénario Make qui intercepte un flux RSS d'actualités technologiques, le fait résumer et noter par l'IA (score de 1 à 10), et envoie une alerte immédiate uniquement si le score est supérieur ou égal à 7.

[1. Flux RSS: TechCrunch] ---> [2. OpenAI / Gemini LLM] ---> [3. Parse JSON] ---> [4. Router] |--> (Score >= 7) ---> [Email / Slack] +--> (Score < 7) ---> [Google Sheets]
1. Capture
Interroger le flux d'informations et isoler le titre et la description de chaque article.
2. Analyse IA
Forcer le LLM à répondre dans un format JSON strict sans bavardage.
3. Routage
Poser un filtre numérique sur la variable générée par le modèle de langage.
Make • Étape 1
Configuration du Déclencheur RSS
Consignes de Configuration
1. Rendez-vous sur make.com et cliquez sur "Create a new scenario".

2. Cliquez sur le bouton central + et cherchez RSS.

3. Choisissez l'action : "Watch RSS feed items".

4. Entrez l'URL du flux de test :
https://techcrunch.com/feed/

5. Fixez Maximum number of returned items à 1.
⚡️ L'Action Clé : "Run this module only"
Faites un clic droit sur la bulle RSS → sélectionnez "Run this module only".

Pourquoi cette étape est cruciale ?
Make a besoin d'exécuter le module une première fois pour "apprendre" la structure des données reçues (variables title, description, date). Ces variables seront ensuite cliquables dans les modules suivants !
⚠️ Attention : Laissez bien la limite à 1 article, sinon Make va aspirer 50 articles d'un coup et épuiser vos opérations gratuites du mois !
Make • Étape 2
Connexion du Modèle IA & Prompt de Structuration
Ajout du Module OpenAI (ou Gemini) & Paramètres
Ajoutez le module OpenAI > Create a Chat Completion. Modèle : gpt-4o-mini (ou gemini-1.5-flash).
Prompt Système Obligatoire (Role: System)system_prompt.txt
Tu es un analyste de veille technologique et stratégique. Pour chaque article fourni, analyse le contenu et renvoie UNIQUEMENT un objet JSON strictement valide au format ci-dessous, sans aucun texte d'introduction ni backticks markdown : { "titre_court": "Titre percutant en 5 mots max", "resume_executif": "Synthèse claire en 2 phrases", "score_pertinence": 8, "thematique": "IA, Sécurité ou Business", "action_recommandee": "Action concrète recommandée" }
📌
Dans le champ User Message : Glissez les variables issues du module RSS :
Titre : {{1.title}}
Contenu : {{1.description}}
Make • Étapes 3 & 4
Parser le JSON & Configurer le Routage Conditionnel
Étape 3 : Le Module "Parse JSON"
Le LLM a renvoyé du texte brut. Pour que Make comprenne le chiffre du score, il faut le parser !

• Ajoutez le module natif JSON > Parse JSON.
• Dans le champ JSON String, déposez :
{{2.choices[].message.content}}.
Étape 4 : Le Routeur & les Filtres
• Ajoutez un module Router.

• Branche 1 (Alerte) : Module Email / Slack.
Cliquez sur la clé à molette entre le Router et ce module → Filtre :
{{3.score_pertinence}} >= 7 (Opérateur numérique).

• Branche 2 (Archivage) : Module Google Sheets pour consigner les articles de score < 7.
🚀
Action de Test : Cliquez sur le gros bouton bleu "Run once" en bas à gauche de Make. Regardez la petite bulle d'inspection au-dessus du module JSON et observez quelle branche du Router s'active !
Pause Active & Débriefing 10 min
Ce que nous venons de faire vs Les Limites de Make
Ce que Make fait à la perfection
• Processus déterministe et linéaire clair.
• Simplicité visuelle pour des profils non-développeurs.
• Plus de 1500 connecteurs prêts à l'emploi en quelques clics.
Où Make montre ses limites
• L'humain doit coder à l'avance tous les scénarios possibles (If/Else rigide).
• L'IA ne peut pas décider d'elle-même d'aller chercher une information imprévue.
• Facturation à chaque bulle : les gros flux deviennent vite coûteux.
La Transition vers le TP 2 : Les Agents IA Autonomes
Et si l'on ne décidait plus à l'avance de chaque branche ? Si l'IA disposait d'une boîte à outils (Calculatrice, Base de données, API Météo) et décidait elle-même quel outil utiliser en fonction de la question de l'utilisateur ? C'est exactement ce que permet n8n grâce à son nœud AI Agent !
n8n • Concept Clé
L'Architecture du Nœud "AI Agent" dans n8n
[When Chat Message Received] (Interface de test web) | v +-------------------------------------------------------------+ | AI AGENT NODE | | (Mode : Tools Agent LangChain) | +--------------+-------------------------------+--------------+ | | | [Model Node] [Memory Node] [Tool Node] (OpenAI / Gemini) (Window Buffer: 5) (Calculator)
1. Sous-nœud Model
Le moteur linguistique (OpenAI, Gemini, Mistral) qui comprend les questions et élabore des plans d'action.
2. Sous-nœud Memory
Maintient l'historique de la conversation pour que l'agent se souvienne de ce qui a été dit précédemment.
3. Sous-nœud Tool
Les mains de l'agent : outils de calcul exact, requêtes en base de données, recherche web, etc.
Théorie Agentique
Comment Raisonne un Agent IA : Le Pattern ReAct
La Boucle de Raisonnement ReAct
Dans un agent, l'IA ne crache pas une réponse d'un bloc. Elle suit une boucle cognitive en 4 temps :

1. Thought (Pensée) : Le modèle analyse le problème ("L'utilisateur demande un calcul complexe, je ne dois pas deviner").

2. Action : Il formule un appel à l'outil approprié ("J'invoque Calculator avec 18 * 849.9").

3. Observation : Il lit le résultat renvoyé par l'outil externe.

4. Final Answer : Il formule la réponse finale pour l'utilisateur.
Trace d'exécution en directExecution Trace
// Ce que l'étudiant va observer dans n8n : Thought: The user asks for a commercial discount calculation. I need to use the Calculator tool. Action: Calculator Action Input: 18 * 849.90 * 0.88 * 1.20 Observation: 16147.20 Thought: I now have the exact result. Final Answer: Le montant total TTC après remise de 12% est de 16 147,20 euros.
n8n • Étapes 1 & 2
Initialiser le Workflow & Insérer l'AI Agent
Étape 1 : Le Déclencheur Chat
1. Ouvrez votre instance n8n (Cloud ou local).

2. Cliquez sur "Add workflow".

3. Cliquez sur "Add first step" et cherchez :
"When chat message received" (Chat Trigger).

Ce nœud ouvre directement un volet de discussion pour chatter avec votre workflow en temps réel !
Étape 2 : Le Nœud "AI Agent"
1. Cliquez sur le bouton + à la sortie du Chat Trigger.

2. Cherchez "AI Agent" (dans Advanced AI).

3. Sélectionnez le mode : Tools Agent.

4. Remarquez les 3 connecteurs colorés sous le nœud : c'est là que l'on branche le cerveau, la mémoire et les outils !
💡
Explication pour les étudiants : Contrairement à Make où les modules sont connectés de gauche à droite sur une seule ligne, le nœud AI Agent de n8n possède des connecteurs verticaux spécialisés pour lui brancher des capacités satellites.
n8n • Étapes 3 & 4
Connecter Model, Memory & Outil Calculator
1. Connecteur Model
Cliquez sur le port Model sous l'agent → Ajoutez OpenAI Chat Model (modèle gpt-4o-mini) ou Google Gemini Chat Model.
2. Connecteur Memory
Cliquez sur le port Memory → Ajoutez Window Buffer Memory. Réglez la taille de l'historique sur 5 messages.
3. Connecteur Tool
Cliquez sur le port Tool → Ajoutez l'outil Calculator. Cet outil garantit l'exactitude absolue des calculs financiers.
Consignes Système de l'Agent (System Message)instructions.txt
Tu es l'assistant commercial d'une société informatique. Tu réponds toujours en français de façon concise et courtoise. RÈGLE ABSOLUE : Dès qu'une question implique un calcul chiffré, des pourcentages, des remises commerciales ou des taxes, tu DOIS impérativement utiliser ton outil "Calculator" pour garantir un résultat exact au centime près. Ne devine jamais les chiffres par toi-même.
n8n • Phase de Test
Tests en Direct & Détection de l'Outil

Cliquez sur l'onglet "Chat" en bas de l'écran n8n et faites exécuter successivement ces 3 tests :

Test 1 : Dialogue sans outil
Question : "Bonjour, que vends-tu comme matériel ?"

Résultat : L'agent répond directement sans appeler l'outil Calculator.
Test 2 : Appel de l'outil
Question : "Un client commande 18 ordinateurs à 849,90 € avec une remise de 12% et 20% de TVA. Quel est le total TTC ?"

Résultat : L'agent invoque la calculatrice et sort le résultat exact : 16 147,20 €.
Test 3 : Test de Mémoire
Question : "Rappelle-moi quel était le prix unitaire d'un ordinateur dont on parlait ?"

Résultat : Grâce au buffer, il se rappelle du prix unitaire : 849,90 € !

Sécurité & Budget
Les 4 Règles d'Or de l'Automatisation en Entreprise
1. Zéro Clé d'API en clair
Ne collez jamais de clé d'API dans un prompt ou un corps de webhook. Utilisez toujours les trousseaux chiffrés (Credentials n8n ou Connections Make).
2. Prévention des Boucles Infinies
Un bot email qui répond à un autre répondeur automatique peut s'auto-répondre 50 000 fois dans la nuit. Toujours filtrer les sujets Out of office ou Auto-reply.
3. Modération des Tokens
Ne pas envoyer 50 pages de document au LLM si 10 lignes suffisent. Nettoyez le HTML et les métadonnées inutiles avant l'appel IA pour réduire vos coûts par 10.
4. Human-in-the-Loop
Pour les actions sensibles (virement d'argent, suppression de base de données, email à un client VIP), l'IA prépare le brouillon et un humain clique sur un bouton de validation.
Quiz Interactif
Validation des Acquis (Questions 1 à 3)
1. Quelle est la différence majeure entre un Polling et un Webhook ?
a) Le polling coûte plus cher.
b) Le polling vérifie périodiquement s'il y a du nouveau, le webhook est alerté instantanément en temps réel. ✔
c) Le webhook ne sait pas transporter de texte.
2. Pourquoi insérer un module "Parse JSON" après un LLM dans Make ?
a) Pour traduire la réponse de l'anglais au français.
b) Pour convertir le bloc de texte brut du LLM en variables individuelles manipulables dans les filtres. ✔
c) Pour masquer la clé d'API.
3. Qu'est-ce qui distingue le nœud "AI Agent" de n8n d'un flux classique ?
a) Il est gratuit sans clé d'API.
b) Il décide lui-même d'invoquer ou non des outils connectés en fonction de la consigne reçue. ✔
c) Il ne fonctionne qu'avec des images.
Quiz & Extension
Validation des Acquis & Mini-Défi
4. Pourquoi confier le calcul à "Calculator" plutôt qu'au LLM ?
a) Les LLMs ont tendance à halluciner sur les calculs précis et arrondis financiers. ✔
b) L'outil Calculator utilise moins de RAM.
c) Le LLM refuse de lire des chiffres.
5. Pour une banque exigeant le respect strict du secret bancaire :
a) Make.com en offre gratuite.
b) n8n déployé en On-premise (Docker interne) couplé à un LLM local souverain (Ollama/Mistral). ✔
c) Zapier Cloud.

• Défi n8n : Connectez un 2ᵉ outil (ex: Wikipedia ou Custom HTTP) et demandez à l'agent : "Quelle est la population de Paris et combien cela ferait-il avec 15% de touristes en plus ?". Observez l'enchaînement des 2 outils !
